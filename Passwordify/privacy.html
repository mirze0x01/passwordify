Passwordify

Privacy and security summary

What stays on this device

The encrypted vault is stored in this browser profile using Chrome's local extension storage. Passwordify has no host permissions, analytics, remote scripts, account system, or network API.

How the vault is protected

  • The master password is never stored.
  • PBKDF2-HMAC-SHA-256 with a random salt and 600,000 iterations derives a key.
  • AES-256-GCM encrypts and authenticates the complete vault with a fresh IV after every change.
  • The derived key and decrypted entries remain only in the unlocked vault page's memory.
  • The page locks after five minutes of inactivity and whenever its tab becomes hidden.

Temporary and clipboard data

Choosing “Save in vault” places the generated password in in-memory extension session storage while the vault opens. Passwordify schedules cleanup after ten minutes and independently rejects an expired handoff when it is read; a suspended device can delay the cleanup alarm. The handoff is removed only after the unlocked vault saves it successfully. Copying a password sends it to the operating-system clipboard; clipboard history or other software may retain it.

Limits of protection

Encryption protects a copied or offline browser profile when the master password is strong. It cannot protect against malware, keyloggers, a compromised browser, malicious accessibility tools, screenshots, or someone using the computer while the vault is unlocked. This project has not received an independent professional security audit.

Deletion and recovery

While unlocked, use “Delete local data” and then “Delete vault” to erase Passwordify's local data. While locked, use “Reset local vault.” You can also uninstall the extension and remove its stored data. There is no password reset or recovery service; losing the master password means losing access to the encrypted vault unless you reset it and start over.
